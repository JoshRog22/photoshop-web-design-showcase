Work Area

The Adobe Photoshop work area is designed to help users efficiently edit and organize images. It includes essential components such as the Tools panel, Options bar, document window, and various panels.

This lesson served as an introduction to the Adobe Photoshop CC workspace and some of its key tools. We began by adjusting brightness and contrast using the Adjustments panel. Next, we created a blue ribbon shape by drawing a rectangle with the Rectangular Marquee tool and filling it using the brush after selecting the color with the eyedropper tool. We then refined the ribbon by using the polygon lasso tool to create the indented edge. Finally, we added text on top of the ribbon using the text tool to complete the design.
