# Photoshop Web Design Showcase

A multi-page website created to showcase foundational Adobe Photoshop skills while applying HTML, CSS, Bootstrap, and web design principles. The site organizes several Photoshop topics into individual pages with consistent navigation and styling.

## Photoshop Topics

### Work Area
Explores the Photoshop workspace and tools used to navigate and manage the editing environment.

### Photo Corrections
Demonstrates techniques used to adjust and improve digital photographs.

### Selections
Explores Photoshop selection tools and techniques for isolating and editing specific areas of an image.

### Layer Basics
Demonstrates the use of layers to organize, edit, and combine visual elements.

### Vector Drawing
Explores vector-based drawing and design techniques within Photoshop.

## Web Development

The Photoshop content is presented through a custom multi-page website with consistent navigation and styling across each section.
